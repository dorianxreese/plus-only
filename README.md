# +++ Only ⚡

> Merchandise and streetwear brand representing positive attraction and mindset. Only positive energy allowed.

## Brand Identity
- **Mission**: Scale positive mindset through intentional merchandise
- **Aesthetic**: Minimalist, bold, symbol-driven
- **Strategy**: Limited drops, community-first, authentic storytelling

## Repository Structure
```
designs/
  product/      # Product design files
  mockups/      # Product mockups
  prints/       # Print-ready files
brand-assets/
  logos/        # Logo variations
  colors/       # Color palette
  fonts/        # Typography
content/
  social/       # Social media content
  drops/        # Drop campaigns
automation/
  printful/     # Printful API integration
  social/       # Social automation
docs/           # Brand guidelines & strategy
```

## Printful Integration
This repo includes automation for:
- Automated mockup generation via Printful API
- Product template management
- Order processing workflows

## Launch Strategy
- **Pricing**: $49-65 per hoodie (mid-market positioning)
- **Drop Strategy**: Limited releases, 100-150 units per design
- **Marketing**: Daily TikTok, 4-5x/week Instagram, community spotlights
