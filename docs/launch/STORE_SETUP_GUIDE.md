# +++ Only - Store Setup Guide

## Recommended: Shopify + Printful

### Setup Steps
1. Create Shopify store ($39/month)
2. Install Printful app
3. Upload products from Printful
4. Design homepage + product pages
5. Configure payments & shipping

### Store Content
**Homepage:** Hero banner + Featured products + About
**Product Pages:** Mockups + Size chart + Descriptions

### Shipping Strategy
- Free shipping on $75+
- Flat $8 under $75
- Printful handles fulfillment
